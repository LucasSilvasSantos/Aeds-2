## Regras atendidas

- Os programas Java importam apenas `java.util.Scanner`.
- Não são usados `equals`, `split`, `compareTo`, `String.format` nem conversores numéricos prontos.
- Os programas C não usam `string.h` nem funções prontas de comparação, cópia, separação ou conversão de strings.
- Comparação, cópia, separação, conversão e formatação foram implementadas manualmente.
- A leitura principal procura o dataset em `/tmp/veiculos.csv`, como exige o enunciado. Para testes locais, há fallback para `../veiculos.csv` ou `veiculos.csv`.

O diretório `casos-publicos` contém as entradas e saídas oficiais baixadas do repositório indicado, e `veiculos.csv` é a cópia oficial do dataset.
